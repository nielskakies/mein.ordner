# Videomaterial hier ablegen

Die Clips in diesen Ordner legen und **durchnummerieren** — die Reihenfolge
im Reel ergibt sich aus der natuerlichen Sortierung der Dateinamen:

    01_ankunft.mp4
    02_aufbau.mp4
    03_detail.mov
    ...
    10_abschluss.mp4

`sort -V` sortiert natuerlich, `10` kommt also korrekt nach `3` — auch ohne
fuehrende Null. Unterstuetzt: mp4, mov, m4v, avi, mkv, webm, mts, 3gp.
